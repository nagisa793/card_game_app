ルール説明・遊び方

手札や左側の一覧からカードを選び、盤面の光る枠に出します。決定やパスはデッキ上のボタンで操作します。対戦は次の順番です。

1. 先攻後攻
2. 盤面構築
3. 戦術手札
4. 攻防
5. 勝敗判定

1．対戦を始める

  • 対COM：自分は下側の「あなた」を操作します。COMの手札と伏せ罠は見えず、COMは約3秒ごとに行動します。
  • COM同士：両者が約3秒ごとに一手ずつ進めます。相手側の手札と伏せ罠は非公開で、マッチ終了まで自動で観戦できます。
  • 先攻と後攻は対戦開始時にランダムで決まります。

2．スタンバイフェイズで盤面を作る

  1. メインデッキから7枚引きます。キャラが0枚なら手札をすべて公開し、デッキへ戻してシャッフルしてから7枚引き直します。
  2. キャラカードをバトルエリアへ出します。バトルエリアは1〜5番の固定枠で、召喚する側が配置先を選びます。キャラが場を離れても残りのキャラの位置は動きません。
  3. 展開カードでキャラの強化、召喚、ドローなどを行います。展開カードによる攻撃力上昇は永続です。援軍指名では異なるキャラ3体を公開し、裏向きにして相手が選んだ1体を召喚します。3体揃わなければ効果は無効です。
  4. 罠カードを作戦エリアへ裏向きで伏せます。作戦エリアは5枠です。
  5. 残ったメイン手札もすべて処理し、手札が0枚になったらスタンバイを終了します。

戦術デッキから選ぶ最初の手札は、先攻が5枚、後攻が7枚です。後攻は先攻の盤面を見て、自分の初期メイン手札を引く前に選びます。先攻は後攻の盤面が完成した後に選びます。選ばなかった戦術カードはシャッフルします。

3．各ターンの操作

  1. ターン開始時、戦術手札が3枚以下なら戦術デッキから1枚引きます。4枚以上なら引きません。
  2. 攻撃するキャラを1体以上選び、相手の攻撃対象を1体選びます。
  3. 複数キャラで攻撃する場合、攻撃側の合計は攻撃対象の攻撃力＋1までです。単騎攻撃にはこの上限がありません。
  4. 攻撃宣言後は防御側から罠・戦術カードを使うかパスします。

4．攻防連鎖と連続発動

  • 攻防連鎖：両者が交互に罠・戦術カードを1枚ずつ発動するやり取りです。両者が続けてパスすると効果処理へ進みます。
  • 連続発動：その表示を持つ一部のカードだけの特殊効果です。自分がカードを発動した直後、相手へ交代せずもう一度自分が発動できます。
  • 戦術カードは作戦エリアの空き枠に表向きで置いて発動します。罠も発動すると表向きになります。
  • 戦術カードによる攻撃力の増減はその攻防ステップ中だけです。罠カードによる増減は永続です。
  • 「総力戦」「一斉妨害」の全員とは、この攻防に参加している側のキャラだけを指します。場にいるだけで参加していないキャラには適用しません。
  • 対象を指定する効果は、攻撃・防御に参加しているかに関係なく、効果が指定する側のバトルエリアにいる全キャラから選べます。標的変更などが未処理でも先回りして指定できます。
  • 発動した戦術・罠カードは攻防連鎖の効果と戦闘結果の処理が終わるまで作戦エリアに残り、その後まとめて撤退エリアへ移ります。
  • 確定した効果は最後に発動したカードから最初のカードへ逆順で処理します。

一時的な効果でLv0になっても、それだけでは撤退しません。攻撃結果の処理後、元Lvが永続的に0のキャラは撤退します。「消えない裂傷」は対象の元Lvを効果処理時に永続−1し、その時点で攻撃力が0なら直ちに撤退させます。

5．攻撃結果

すべての効果処理後、攻撃側の参加キャラの合計攻撃力と攻撃対象1体の攻撃力を比べます。

  • 攻撃側が上回る：攻撃対象が撤退します。
  • 防御側が上回る：攻撃に参加したキャラがすべて撤退します。
  • 単騎対単騎で同数：両方の元の攻撃力を永続で1下げます。Lv0になったキャラは攻撃結果の完了時に撤退します。
  • 複数対単騎で同数：単騎側の攻撃力を永続で1下げ、単騎側が複数側から撤退させるキャラ1体を選びます。

6．パスと勝敗

  • 攻撃宣言をパスした回数は、あとで攻撃しても消えずに累積します。2回目のパスから除外ペナルティが発生し、回数ごとに重くなります。
  • 相手のキャラがすべていなくなると勝利です。両者同時に全滅した場合は残っている罠・戦術カードの枚数で判定します。
  • 両者とも作戦エリアの罠・戦術手札・戦術デッキが完全に0枚になった場合もゲーム終了です。その場合は残っているキャラの攻撃力合計で判定します。
  • 完全に同点なら得点を付けず、先攻後攻を再抽選して再試合します。
  • 2勝を先取した側がマッチ勝利です。

画面の補助機能

  • 盤面のカードや山札を押すと、右側の「CARD INFORMATION」に詳細が表示されます。
  • 青く発光しているカードや枠は選択可能です。右側の操作ボタンだけでなく盤面を直接押しても選べます。
  • 攻撃キャラと攻撃対象は横向きになります。操作欄でキャラを選ぶと、対応する盤面のカードが緑色に強調されます。
  • 左端の縦長の「攻防連鎖」には攻撃宣言・パス・発動カード・対象・処理結果が最新順で残ります。そのすぐ右、盤面左側の縦レーンには現在進行中のCHAINとRESOLVEを表示します。
  • カードの詳細は盤面右側、両者の山札より右にある「CARD INFORMATION」で確認できます。
  • 「一つ戻る」「一つ進む」で操作をやり直せます。
  • 上部の「演出設定」で画面の動きと処理レーンの強調表示を変更できます。攻防連鎖と対戦履歴は折り畳めます。
  • 各カード固有の詳しい条件は「操作」に表示されるカード本文を確認してください。
